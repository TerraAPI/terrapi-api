## R-tree spatial index tables (all files)

Each administrative table with a `geom` column has four companion rtree index tables, auto-generated by the GPKG/SpatiaLite extension. Examples for `cont_distritos`:

```
rtree_cont_distritos_geom
rtree_cont_distritos_geom_node
rtree_cont_distritos_geom_parent
rtree_cont_distritos_geom_rowid
```

Same pattern applies to all `{prefix}` + `_distritos`, `_municipios`, `_freguesias`, `_nuts1`, `_nuts2`, `_nuts3`, `_areas_administrativas`, `_trocos`.
